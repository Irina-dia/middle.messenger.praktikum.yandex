# Описание проекта:

Учебный проект курса **«Мидл фронтенд-разработчик»** Яндекс Практикума.

Веб-приложение «Чат» с реализацией авторизации, регистрации, профиля пользователя и страницы чатов. Проект построен на TypeScript с использованием компонентного подхода, собственного класса `Block`, шаблонизатора Handlebars и сборщика Vite.

- Установить зависимости: `npm install`

## Функциональность

### Авторизация и регистрация

- регистрация нового пользователя;
- авторизация;
- выход из аккаунта;
- автоматическая проверка авторизации;
- защита приватных страниц;
- перенаправление неавторизованного пользователя на страницу входа.

### Профиль пользователя

- просмотр данных пользователя;
- редактирование профиля;
- изменение:
  - email;
  - логина;
  - имени;
  - фамилии;
  - имени в чате;
  - телефона;
- изменение пароля;
- проверка совпадения нового пароля и подтверждения;
- загрузка и изменение аватара;
- изменение аватара доступно только в режиме редактирования профиля.

### Чаты

- получение списка чатов;
- создание нового чата;
- выбор активного чата;
- добавление пользователя в чат по логину;
- удаление пользователя из чата по логину;
- открытие и закрытие меню управления чатом;
- открытие и закрытие popup добавления/удаления пользователя.

### Роутинг

Реализован клиентский роутинг со следующими маршрутами:

- Авторизация — `/`
- Регистрация — `/sign-up`
- Мессенджер — `/messenger`
- Профиль пользователя — `/settings`
- Страница 404 — `/404`
- Страница 500 — `/500`

Реализованы:

- переходы между страницами без полной перезагрузки;
- навигация кнопками браузера «Назад» и «Вперёд»;
- сохранение текущего маршрута при перезагрузке страницы;
- защита приватных маршрутов;
- отображение только одной страницы в DOM.

## Работа с API

Для взаимодействия с API используется собственный класс `HTTPTransport`.

Поддерживаются HTTP-методы:

- GET;
- POST;
- PUT;
- DELETE.

Для GET-запросов реализована передача параметров через query string.

Для остальных запросов данные передаются в body.

Для загрузки файлов используется `FormData`.

Все HTTP-запросы выполняются через `XMLHttpRequest` и `Promise`.


## Архитектура

В проекте используются:

- компонентная архитектура на основе собственного класса `Block`;
- собственный `Router`;
- собственный `HTTPTransport`;
- Store для хранения состояния приложения;
- отдельные API-классы для работы с сервером;
- Handlebars для шаблонов;
- Validator для клиентской валидации форм.
