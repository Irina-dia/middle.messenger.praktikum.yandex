# Описание проекта:

Учебный проект курса **«Мидл фронтенд-разработчик»** Яндекс Практикума.

Веб-приложение «Чат» с реализацией авторизации, регистрации, профиля пользователя и страницы чатов. Проект построен на TypeScript с использованием компонентного подхода, собственного класса `Block`, шаблонизатора Handlebars и сборщика Vite.

## Установка и запуск

- Установить зависимости: `npm install`
- Запустить проект: `npm run start`
- Собрать проект: `npm run build`
- Проверить типизацию и линтеры: `npm run lint`

## Доступные страницы

- Авторизация — `/#auth`
- Регистрация — `/#reg`
- Чаты — `/#chat`
- Профиль — `/#profile`
- Ошибка 404 — `/#404`
- Ошибка 500 — `/#500`
